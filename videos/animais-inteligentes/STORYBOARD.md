# Storyboard: E se os animais fossem tão inteligentes quanto os humanos?

## Bíblia de estilo
1. Cinema 3D R10 (`createToyStage`: PBR, grão, vinheta, câmera na mão, dip entre cortes, bloom) + tipografia doc (kicker mono azul, palavra-chave `.y`).
2. Helper do vídeo: `assets/lib/blocks/mente.js` (corvo, cão, vaca, galinhas instanciadas, cérebros de pontos, palco de diagrama, fundo do mar, skyline, texto 2D preso ao 3D, `leve()` para cortar triângulos).
3. Alterna: macro realista (corvo) → savana → diagrama escuro de neurônios → oceano → pedra/vila → cidade → blocos 3D → fazenda → parque → corvo de novo.
4. Azul `#7cc8ff` = mente/neurônios; laranja `#ff8a4c` = anomalia (cerebelo do elefante, braços do polvo, gado, "direitos").
5. Números desenhados no canvas e nos rótulos no momento em que são ditos (`palavras.json`), em y 520–1000 ou abaixo da legenda.
